# SDP Quotation System

New full-stack quotation/order management system for SDP Machines.

## Planned core flow

Create Document -> Preview PDF -> Approve -> Send Email / Download -> Documents List

## Tech stack

- Next.js + TypeScript
- Tailwind CSS
- Prisma
- MySQL
- Nodemailer

## Local setup

1. Run `npm install`
2. Run `npm run dev`
3. Open `http://localhost:3000`

Database/authentication are intentionally not wired yet. The initial scaffold freezes the agreed page structure before we build the data model.
